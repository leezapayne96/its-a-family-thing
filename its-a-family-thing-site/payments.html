How to set up Stripe (5 minutes)

  1. Create a Stripe account (or sign in).
  2. Go to Payment Links → Create → choose “Reunion Dues”.
  3. Set amount (or multiple options), add description, then publish.
  4. Copy the Payment Link URL.
  5. Paste it into js/config.js as STRIPE_PAYMENT_LINK.
Want a full “Checkout” flow with custom fields? That requires a small backend. Payment Links are the easiest and still look professional.
