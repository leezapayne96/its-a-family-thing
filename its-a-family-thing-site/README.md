# It’s a Family Thing — Family Reunion Website (Orlando • July 2–6, 2026)

## What this is
A colorful, family-friendly, ready-to-use static website with:
- Home
- RSVP (saved to your device + CSV download)
- Schedule
- Payments (Stripe Payment Link button + optional “mark paid” tracking on device)
- Things to do in Orlando (with booking links)

## Quick start (Mac)
1) Unzip the folder
2) Open `index.html` in your browser (double-click)

## Edit basics
Open `js/config.js` and update:
- `STRIPE_PAYMENT_LINK`
- dues text + contact info

## Publish free (GitHub Pages)
1) Create a GitHub repo
2) Upload all files
3) Repo Settings → Pages → Deploy from branch → `main` / root
4) Your site will be live at the URL GitHub provides.

## Make RSVPs collectable by everyone
This demo saves RSVPs locally (per-device). To collect RSVPs:
- Embed a Google Form, or
- Use Formspree / Airtable / other form backend.

Enjoy! 🎉
